# 통깡이 기다리기 - 비공개 우선 사이트

## 실행
1. PC에 Node.js 18 이상 설치
2. 이 폴더에서 터미널/명령 프롬프트 열기
3. `npm start` 실행
4. 브라우저에서 `http://localhost:3000` 접속

첫 접속 시 관리자 계정 1개를 만듭니다. 아이디 3자 이상, 비밀번호 10자 이상.
관리자 계정은 최초 1회만 생성되며 추가 계정 생성 기능은 없습니다.

## 비공개 / 공개
- 기본 상태는 비공개입니다. 일반 방문자는 사이트 내용과 댓글을 볼 수 없습니다.
- 관리자로 로그인한 뒤 관리자 패널에서 공개 전환을 누르면 방문자에게 공개됩니다.
- 다시 비공개로 전환할 수도 있습니다.

## 주요 기능
- 익명 댓글 500자, 댓글 목록 및 날짜별 필터
- 홈 화면 메시지 흐름 애니메이션
- 오늘 댓글 수 / 오늘 글자 수 / 방문 수
- `시작 날짜` 설정 및 한국 시간 기준 날짜 카운터
- 관리자 댓글 삭제
- 데이터는 이 서버의 `data.json`에 저장됩니다.

## 인터넷 공개 전 알아둘 점
현재 기본값은 로컬 비공개 실행입니다. 인터넷에서 다른 사람이 접속하게 하려면 HTTPS를 지원하는 Node 호스팅에 이 폴더를 배포해야 합니다. 호스팅은 서버를 계속 켜 두고 `data.json`을 보존하는 영구 저장 디스크를 지원해야 합니다. 공개 URL에 올리기 전 반드시 관리자 비밀번호를 강력하게 설정하세요.
이 프로젝트는 별도 DB가 없는 소규모 시작용입니다. 트래픽이 커지면 PostgreSQL 등의 데이터베이스로 이전하는 것을 권장합니다.

## 보안 메모
- 관리자 비밀번호는 scrypt 해시로 저장합니다.
- 관리자 세션 쿠키는 HttpOnly / SameSite=Strict입니다.
- 운영 배포에서는 반드시 HTTPS를 사용하세요.
- 서버를 재시작하면 현재 로그인 세션은 종료됩니다.
